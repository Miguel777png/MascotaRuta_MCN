1. ¿Cuál es la función principal del Android Runtime (ART) en la ejecución de aplicaciones?

B) Ejecutar aplicaciones utilizando compilación anticipada (AOT) para mejorar el rendimiento y eficiencia energética.

2. ¿Qué capa de la arquitectura de Android actúa como puente entre los controladores del Linux Kernel y el Java API
   Framework?

A) Hardware Abstraction Layer (HAL).

3. Al presionar el botón 'Atrás' del sistema y salir de una Activity, ¿qué callbacks del ciclo de vida se ejecutan
   secuencialmente?

A) onPause() -> onStop() -> onDestroy().

4. ¿Cuál es el propósito del archivo AndroidManifest.xml en la arquitectura de un proyecto Android?

C) Declarar los componentes esenciales de la app (Activities, permisos, servicios) ante el sistema operativo.

5. ¿Qué sucede si se intenta iniciar una nueva Activity que NO está declarada en el AndroidManifest.xml?

B) El sistema operativo gatilla una excepción crítica ActivityNotFoundException y la app se cierra.

6. ¿Para qué se utiliza la combinación de banderas FLAG_ACTIVITY_CLEAR_TOP y FLAG_ACTIVITY_SINGLE_TOP en un
   Intent?

B) Para buscar una instancia existente de la Activity destino, destruir las intermedias y traerla al primer plano.

7. ¿Qué componente de arquitectura se encarga de compartir datos de forma segura entre distintas aplicaciones
   instaladas?

C) Content Providers.

8. ¿Por qué es recomendable utilizar la unidad 'sp' para definir el tamaño de texto (textSize) en los archivos XML?

B) Porque escala según la densidad de pantalla y respeta la preferencia de accesibilidad configurada por el usuario.
